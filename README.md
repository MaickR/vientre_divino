## 📖 Acerca del Proyecto

**Vientre Divino** es una experiencia digital de transformación femenina. Una plataforma web moderna que conecta mujeres con un retiro profundo de sanación ancestral, reconexión con lo femenino y liberación de patrones heredados en Mount Shasta, California.

### 🎯 Propósito

Ofrecer un espacio seguro, íntimo y transformador donde mujeres puedan:
- Reconectar con su sabiduría femenina
- Liberar memorias y patrones del linaje
- Transitar de la supervivencia (Amazona) a la magia (Maga)
- Habitarse desde la intuición, el amor y la creatividad

## 📋 Cómo Personalizar

### Cambiar Números de Contacto
Busca `14086502198` en `index.html` y reemplaza por tu número WhatsApp (formato: país + número sin espacios)

### Actualizar Paleta de Colores
Las variables CSS están en `:root` al inicio del archivo `<style>`

### Modificar Contenido
Todas las secciones están comentadas en el HTML para fácil identificación

### Agregar Nuevas Secciones
Sigue la estructura: `.section` → `.container` → contenido con `.reveal` para animaciones
